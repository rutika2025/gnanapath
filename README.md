# GnanaPath (ಜ್ಞಾನಪಥ)
Learn physics. Fix every gap.

An adaptive AI tutor for KSEEB Class 10 Science: Electricity. Built for the Product Space Agentic AI Hackathon.

## Features
- Diagnostic quiz with live mastery heatmap
- Concept graph with prerequisite tracing
- AI misconception detection from typed reasoning
- AI practice questions with difficulty calibration
- Spaced-repetition revision schedule
- Exam readiness score, with Chapter 2 unlocking at 80%
- Teacher dashboard for class-wide gaps (sample data)
- English and Kannada
- Daily streak and XP
